# v8 — `work scan` is now `work doctor`

**What changed:** The conflict-scanning command is renamed. Every other plugin calls its
read-only checker `doctor`, this one called itself `scan` while its own docs described it as "the
work doctor", and the odd one out was the one people had to remember.

**Preconditions:** the bus has a `## Commands` section with a `Doctor` column (v7). Decline with
"waiting on v7" otherwise.

**Apply (v7 → v8):**

1. **Update the `delivery` row's `Doctor` cell** in `## Commands` from `work scan` to
   `work doctor`. If it already says `work doctor`, or the cell is empty, leave it alone.

2. **Leave every other cell and row untouched**, including other roles' doctors.

3. **Tell the user the old name is gone**, in one line: `/work:scan` no longer exists and
   `/work:doctor` does the same thing. Nothing in the repo needs changing beyond the row above —
   but any alias, script or note of theirs that types the old name will stop working, and this
   migration cannot find those.

`[note]` The procedure file moved with it (`_shared/scan.md` → `_shared/doctor.md`), which
matters only to anyone reading the plugin's own source.
