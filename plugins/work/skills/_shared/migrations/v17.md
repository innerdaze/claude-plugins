# v17 — `.agent/local` is ignored as a path and linked

**What changed:** Every ignore entry written for the local folder so far was `.agent/local/`, with a
trailing slash. A slash pattern matches a directory only, so it **misses a symlink** — and the
folder is meant to be a symlink, shared across a developer's worktrees. Nothing created that link
either; v12 told the user to make it by hand. Now the entry is `.agent/local` (no slash), and
`.agent/local` is created as a link to one folder every worktree shares.

Two reasons:

- **A slash entry stops matching the moment the folder becomes a link**, and an ignore entry that
  matches nothing looks exactly like one that works until a local file shows in a diff.
- **Sharing by hand is sharing nobody does.** A preference belongs to the person, not the
  checkout, so the folder should be the same one in every worktree without anyone remembering to
  link it.

**Preconditions:** the bus lives at `.agent/PROJECT.md` (v4). Decline with "waiting on v4"
otherwise.

**Apply (v16 → v17):**

1. **Apply `${CLAUDE_PLUGIN_ROOT}/checks/LOCAL-DIR.md`, steps 1–4, for this worktree.** In short:
   ignore `.agent/local` (no slash) in the ignore file and the shared `info/exclude`, rewriting an
   existing slash line in place; make `.agent/local` a link to the shared folder under the common
   git directory, asking wherever the file says to ask; then report. Follow that file rather than
   this summary — it owns the procedure.

2. **Do not move another role's local files.** Anything already in the folder stays where it is
   and keeps its name; the section's own collision check governs what moves when a plain folder
   is converted into the link.

**Idempotent.** A project already on the no-slash entry with a working link changes nothing, and
the report says so.

**Other worktrees.** This migration's stamp is committed, so a second worktree never re-runs it.
Each other worktree gets its link from `work init` or from `cadence` session start, which apply
the same section. Until then it keeps a plain `.agent/local` of its own, which the no-slash entry
still ignores.
