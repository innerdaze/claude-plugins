# v7 — a `Doctor` column in `## Commands`

**What changed:** `## Commands` gained a **Doctor** column, so a doctor can name every other
role's doctor rather than only its migrate command. Each owner fills its own row.

**Preconditions:** the bus has a `## Commands` section (v3). Decline with "waiting on v3"
otherwise.

**Apply (v6 → v7):**

1. **Add the column** to the existing table, and fill **only** the `delivery` row:
   `| delivery | work migrate | work init | work doctor |`.

2. **Leave every other role's cells as they are**, including empty ones. A role with no doctor
   declared has none, and inventing a plausible command name for another tool is the guess this
   table exists to remove. Their owner fills it when it next runs.

`[note]` This migration is only possible because **`## Commands`' row shape is deliberately not
frozen**, unlike `## Artifacts` and `## Versions` beside it. Adding a column to either of those
would be a frozen-core change and therefore unavailable forever — which is exactly why the
section was created with that exemption stated in the file.
