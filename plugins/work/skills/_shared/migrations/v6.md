# v6 — binding rows for the seams `work` consumes

**What changed:** The config bus gained a **`Doc system`** and an **`Intent`** binding row
alongside the existing `Shared knowledge` one. Each names a *kind*, which a tool resolves to a
project-local adapter, else that kind's shipped fallback. `work` now reads these rows instead of
assuming what is present.

**Preconditions:** the bus lives at `.agent/PROJECT.md` (v4). Decline with "waiting on v4"
otherwise.

**Apply (v5 → v6):**

1. **Add the two rows** to the bus's config table if absent, and **derive their values from what
   the project actually has** rather than defaulting blindly:

   | Row | Set to |
   |---|---|
   | `Doc system` | `markdown` **if** a `knowledge` row exists in `## Artifacts` *and* its path exists; otherwise `none` |
   | `Intent` | `markdown` **if** an `intent-layer` row exists in `## Artifacts` *and* its path exists; otherwise `none` |

   **Write the value in backticks**, exactly as the other binding rows in the bus are written:
   the cell reads ``| Doc system | `markdown` |``, not `| Doc system | markdown |`. The backticks
   are how every binding row in `templates.md` is formatted, and a migration that writes the bare
   word produces a different diff from one that does not — for the same project, from the same
   starting state. Consumers should still tolerate either, but only one of them is what this
   migration writes.

   A row that already has a value is left exactly as it is — a project-local adapter someone
   generated outranks anything this migration would infer.

2. **Do not create either artifact**, and do not scan for one. The rows describe what is
   registered; an unregistered artifact stays unregistered until its owner runs. Guessing here
   would reintroduce the path-detection the registry exists to remove.

3. **Say what changed for this project**, one line, only if it applies: a `Doc system` of `none`
   where a `domains/` folder is present means knowledge will not load until the tool that owns it
   is installed. That is the upgrade regression, and it is worth naming at the moment it becomes
   true rather than at the moment someone notices.
