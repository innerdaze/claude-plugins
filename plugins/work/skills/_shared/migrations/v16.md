# v16 — a parked key that repeats a shared value is dropped

**What changed:** v10 parked every legacy key it did not recognise in a
`## Configuration <!-- owner: shared, additive -->` section, so nothing was lost and a reviewer
could move each one by hand. In practice nobody did, and another tool's migration then wrote the
same values into the frozen sections — cadence's v1 filled `## Tracker` from its own config while
`## Configuration` still held the legacy `Ticket tracker` row with the same value. The bus stated
one fact twice, every doctor reported it, and the remedy they named — the delivery role's migrate
— did nothing, because the delivery stamp was already current.

**Preconditions:** the bus lives at `.agent/PROJECT.md` (v4). No `## Configuration` section →
nothing to do; continue to the stamp.

**Apply (v15 → v16):**

1. **For each row in `## Configuration`, compare its value** — trimmed, case-insensitive — with
   every value in the five `shared` settings sections (`## Project`, `## Environment`,
   `## Version control`, `## Tracker`, `## Verification`) and in `## Bindings`. **Equal to one of
   them → drop the parked row.** The fact is stated once, in the section that owns the concept,
   and the parked copy is the one with no owner behind it.

2. **A parked row whose value appears nowhere else stays**, and is **named in the report** with
   the section it most plausibly belongs to — as a suggestion for a person, never as an edit.
   Which section owns a key the template never knew is not a deterministic question, and a
   migration that guessed would produce a different bus for every developer who ran it.

3. **Remove `## Configuration` entirely when it is empty afterwards.** A section with no rows and
   nobody to write into it is a heading a reader has to explain.

4. **Touch no other section.** The shared values that made a parked row redundant are exactly as
   they were; you compared against them, you did not edit them.

5. **Report**: each row dropped with the section that already held its value; each row kept with
   the suggested home; and, where rows remain, that the fix is a hand edit — no command moves a
   key into a section on your behalf.

`[note]` The check every doctor runs for this (`BUS-CHECKS.md` § 2) names this migration as the
remedy only while the delivery stamp is behind. Once it is current and rows remain, the doctor
says *hand edit* — because naming a command that will do nothing is how a finding gets ignored.
