# v1 — the knowledge system as extracted from `work`

**What changed:** Nothing, structurally. The knowledge system moved from being scaffolded by
`work init` to being owned by this plugin, and its shape is unchanged — so a project already
running it is **already at v1** and needs no conversion.

**Preconditions:** none.

**Apply (→ v1):** Nothing to apply. This file exists so the floor has something to point at, and
so the history records that v1 is an *ownership* change rather than a format change.

The one thing a project may be missing is its **bus registration** — the `knowledge` rows in
`## Artifacts`, `## Versions` and `## Commands`, which `work` never wrote because the role did
not exist yet. `domains init` adds them (its Step 7) and is safe to re-run for exactly this
purpose.
