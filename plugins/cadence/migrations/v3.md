# v3 — stop keeping the project's name and prefix twice

**What changed:** The `project:` block leaves cadence's config. `project.name` and
`project.ticket_prefix` are the config bus's `## Project` → `Name` and `## Tracker` → `Prefix`,
and keeping a second copy is the drift the bus exists to prevent.

v1 moved `tracker`, `vcs`, `execution` and `doc_system` out under exactly this rule — *present ⇒
read it, drop your copy* — and left `project` behind. This finishes that job. It was found by
writing out cadence's config set option by option, which is a good argument for doing so.

**Preconditions:** the bus is at `.agent/PROJECT.md` and has a `## Project` section (delivery
v10). Decline with "waiting on the bus" otherwise — dropping a value before its replacement
exists would lose it.

**Apply (v2 → v3):**

1. **Compare before dropping.** For each of the two values, read the bus's version and cadence's:

   | cadence | bus |
   |---|---|
   | `project.name` | `## Project` → `Name` |
   | `project.ticket_prefix` | `## Tracker` → `Prefix` |

   - **Bus has it and they agree** → drop cadence's copy. Nothing is lost.
   - **Bus is missing the row** → write it from cadence's value first, then drop. `## Project` and
     `## Tracker` are `shared`: writing an absent row is exactly what that permits.
   - **They disagree** → **stop and report both**, with which file each came from. One of them has
     been edited since the other, and which is current is a fact about this project that neither
     file records. Offer to keep the bus value, keep cadence's (writing it into the bus), or stop
     and reconcile by hand.

2. **Remove the `project:` block** once both values are accounted for. If it holds any key other
   than those two, **leave the block with just that key and report it** — an unrecognised key is
   somebody's, and this migration knows about two.

3. **Leave everything else alone**: `flow`, `dod_gates`, `tracker.status_map`, `session_state`,
   `models`, `cadence_version`. Those are methodology or cadence's own, and they stay.

4. **Report** what you dropped, anything you wrote into the bus, and any disagreement you stopped
   on.

`[note]` After this, cadence's private config holds only what no other tool could use: the flow,
the gates a project adds, the lane-to-status map, where its scratchpad lives, its model tiers and
its contract stamp. That is the test the split was supposed to apply, and now does.
